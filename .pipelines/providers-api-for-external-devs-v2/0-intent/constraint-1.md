# Constraint 1: The spec leaves how the change is built to the design

The spec doesn't prescribe how the change is built: not how a provider's files are laid out or registered, not which tool reports a missing part, and not how the package's boundaries are enforced. Remove those parts from these requirements and the criteria that test them, and keep what they require.
